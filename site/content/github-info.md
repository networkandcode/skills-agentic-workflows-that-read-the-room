## Recent updates

### GitHub Copilot

- **Slash commands in the Copilot app** — The Copilot app supports slash commands for planning, collaborating, automating, and customizing workflows. Go beyond chat by using `/` to trigger specific actions. *(GitHub Blog, Aug 6, 2026)*
- **Stacked sessions and pull requests** — You can now use stacked sessions and pull requests in the GitHub Copilot app to modernize large codebases incrementally, keeping each change reviewable. *(GitHub Blog, Jul 30, 2026)*
- **Copilot SDK for Java** — Enterprise Java developers can now drive GitHub Copilot from idiomatic Java code using the Copilot SDK, with support for annotations and virtual threads. *(GitHub Blog, Aug 6, 2026)*
- **Copilot CLI for non-coders** — GitHub's own legal team used Copilot CLI to build automation tools without writing code, showing Copilot's utility beyond engineering. *(GitHub Blog, Aug 4, 2026)*

### Agentic development

- **From coder to orchestrator** — Developers are increasingly owning the full delivery system around code, not just code itself. Agents shift the role from writing code to directing systems. *(GitHub Blog, Aug 10, 2026)*
- **AI-generated PRs → reviewable stacks** — Instead of one huge un-reviewable pull request from a coding agent, use GitHub stacked pull requests to decompose agent work into clean, ordered, reviewable slices. *(GitHub Blog, Aug 4, 2026)*
- **Awesome Copilot Skills** — The community-curated [Awesome Copilot](https://awesome-copilot.github.com/) site lists 407+ skills, agents, and instructions for GitHub Copilot. Skills include codebase mapping, agent governance patterns, and OWASP compliance checks for AI agents.

### Security & supply chain

- **Malware advisories beyond npm** — GitHub now surfaces malware advisories across more ecosystems by integrating OpenSSF's malicious-packages data into the Advisory Database. *(GitHub Blog, Aug 6, 2026)*
- **Tame Dependabot** — Group Dependabot updates by ecosystem or package pattern and slow the PR cadence for non-security updates, while keeping security patches fast. *(GitHub Blog, Jul 28, 2026)*
- **npm and Actions supply chain hardening** — GitHub has shipped changes across npm and GitHub Actions to disrupt common supply chain attack techniques and limit blast radius. *(GitHub Blog, Jul 28, 2026)*
