## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates

### From the GitHub Blog

- **From coder to orchestrator** — AI agents are changing the developer role from writing code to directing autonomous agents. Worth reading if you're thinking about where your skills are headed.
  _Source: [github.blog](https://github.blog/developer-skills/career-growth/from-coder-to-orchestrator-how-agents-shift-the-role-of-a-developer/)_

- **Slash commands in the GitHub Copilot app** — A practical guide to using `/fix`, `/explain`, `/tests`, and other slash commands directly inside the Copilot app to speed up common tasks.
  _Source: [github.blog](https://github.blog/ai-and-ml/github-copilot/a-guide-to-slash-commands-in-the-github-copilot-app/)_

- **Stacked sessions and pull requests in Copilot** — You can now open stacked Copilot sessions and link them to pull requests, making it easier to review AI-assisted work in context.
  _Source: [github.blog](https://github.blog/ai-and-ml/github-copilot/stacked-sessions-and-pull-requests-in-the-github-copilot-app/)_

- **Tame Dependabot** — Group dependency updates, slow the cadence for non-critical packages, and keep security patches fast. A sensible setup guide for busy repos.
  _Source: [github.blog](https://github.blog/security/supply-chain-security/tame-dependabot-group-your-updates-slow-the-cadence-keep-security-fast/)_

- **Turn one large AI PR into a reviewable stack** — Practical advice on splitting giant AI-generated pull requests into smaller, reviewable units without losing context.
  _Source: [github.blog](https://github.blog/engineering/turn-one-giant-ai-generated-pull-request-to-a-reviewable-stack/)_

### From the GitHub Changelog

- **Copilot memory and Ollama in JetBrains** — GitHub Copilot for JetBrains now supports persistent memory across sessions and local Ollama models for offline use.
  _Source: [github.blog/changelog](https://github.blog/changelog/2026-08-11-copilot-memory-and-ollama-in-github-copilot-for-jetbrains)_

- **MAI-Code-1.1-Flash available in Copilot** — Microsoft's MAI-Code-1.1-Flash model is now selectable in GitHub Copilot. Note: MAI-Code-1-Flash is being deprecated.
  _Source: [github.blog/changelog](https://github.blog/changelog/2026-08-11-mai-code-1-1-flash-available-in-github-copilot)_

- **Per-model token breakdown in usage reports** — The Copilot usage report now breaks down token consumption by model, making it easier to track costs and optimize model selection.
  _Source: [github.blog/changelog](https://github.blog/changelog/2026-08-11-per-model-token-breakdown-in-the-usage-report)_

- **Copilot on web expands conversation controls** — The web version of Copilot Chat now has more controls for managing and navigating conversations.
  _Source: [github.blog/changelog](https://github.blog/changelog/2026-08-10-copilot-on-web-expands-conversation-controls)_

- **Auto-migrate branch protection rules to rulesets** — GitHub now offers automatic migration of branch protection rules to the newer repository rulesets format.
  _Source: [github.blog/changelog](https://github.blog/changelog/2026-08-11-automatically-migrate-branch-protection-rules-to-repository-rulesets)_

- **GitHub Enterprise Server 3.22 RC** — Release candidate for GHES 3.22 is available for testing.
  _Source: [github.blog/changelog](https://github.blog/changelog/2026-08-11-github-enterprise-server-3-22-release-candidate)_
